# A1 Research Depth / Retry Guard V1

This change does not promote or trade anything. It changes research admission only.

Before a new A5 heavy replay is allowed, the guard requires a sufficiently broad high-tier evidence corpus, mechanism and limitation extraction, multiple source families, prior-attempt/terminal-identity checks, exact canonical baseline integrity, source granularity compatible with the claimed mechanism, and the existing two-pass/zero-reject review policy.

Known technical/provider failures remain retriable under the same frozen identity; valid economic/no-effect terminals do not. Fresh validation remains A1 -> A2 -> A3, with no parent-pass or historical substitution.
