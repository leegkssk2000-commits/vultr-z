# Q4R3 R0 Owner Matrix Fields

Each component row must contain:

- canonical component name
- canonical package path
- implementation kind
- SHA-256
- Git tracked state, commit, and commit timestamp
- contract version evidence
- active unit bindings
- resolved ExecStart and script paths
- symlink and wrapper chains
- direct order or sensitive credential access evidence
- tests and contracts
- KEEP/ABSORB/RESERVE/QUARANTINE/ARCHIVE recommendation
- recommendation reason
- unresolved evidence

R0 cannot infer ownership from role words alone. It must expose competing candidates and refuse uniqueness when evidence is insufficient.
