# 벤치마킹 실측 해석 — 엔진과 전략을 분리

## 실제로 끝낸 비교

Freqtrade2026.8 실제 Backtesting 엔진에서 독립 구현한 Break V2와 공개 Heracles 원형을 각각 두 기사용 기간에서 실행했다. 신규 실제 적용69~72, 외부 참조 가설48이다. 기존47가설/68평가와 D/D2/KR3/Break 부모·원천·OOS·API 이력은 보존했다. 새 시세 수집·미사용OOS·실주문·프로젝트 유료AI는0이다. 플랫폼/CI 자체의 비용은 별도 미측정이다.

예비시험 첫 run34248952803은 green이지만 Python 설정 누락(max_open_trades)으로 실패했다. tee가 종료코드를 가린 우리 workflow 오류였다. 경제입력 전에 공식 StrategyResolver의 클래스 발견만 교체하고 나머지 공식 속성/매개변수 처리를 유지하도록 수선했다. set -euo pipefail과 성공 marker 검사도 추가했다. 이 최초 합성 실패는 경제실행으로 세지 않으며 성공으로 보고하지 않는다. 수정된 run34249737131은 실제 합성 엔진 PASS와 같은 입력 준비를 완료했다.

본 경제 run34250475392/job102143325404는8개 사전 합성시험, 엔진 거래 시험, 실제 Heracles 매개변수 로딩 시험을 통과한 뒤4개를 순서대로 실행했다. 각 실제 예약/예산을 git push하고 원격SHA를 읽어 확인한 뒤 compute에 들어갔다. 코드와 규칙은 결과 후 바꾸지 않았다. 결과 commit863243f0382c0187807f7b1e4fd7b5e3cb3f2681 및 artifact10065819623에 보존됐다. 최종 CI/리뷰/병합 상태는 별도 완료 기록을 따른다.

## 1. 엔진 비교 결과

2025 원신호283개,2026 원신호90개가 외부 독립 feature 구현과 저장 ZEL 원장에서 모두 일치했다. 공통 완결 거래155/52건의 진입가격·종료시각·원래 모형 비용도 일치했다. 전체 종가 시퀀스가 같은 EMA값으로 계산되는지 전 지표 값을 독립 교차검증한 결과라고 확대하지 않는다.

차이는 원래 H6 마지막 보유봉 종가와 Freqtrade 같은 경계의 다음 시가였다. 공통 거래 순손익 증분은2025 +18.371639960774,2026 +7.821635844036 trade-bps다. 또한 Freqtrade는 마지막 실제 봉에 신규진입하지 않아2025의 원래 PEPE 미완결1건(-191.710817548520)이 빠졌다. 따라서2025 전체 차이 +210.082457509295 = 공통 가격차이18.371639960774 - 빠진 미완결(-191.710817548520)으로 일치한다.2026은 공통 거래 가격차이만 전체 증분과 일치한다.

**엔진 교체로 전략 수익성이 갑자기 좋아진 결과가 아니다.** 신호와 주요 생명주기는 맞고, 체결가격·평가창 끝 처리 관례의 차이가 드러난 것이다. native 결과를 강제로 덮어 같게 만들지 않았다. 이번 범위에서 Break의 개발 성적이 자체 엔진만의 가짜 숫자라는 근거는 없으나 D2·Q0·전체 운영 경로까지 검증한 것은 아니다.

## 2. 외부 전략 결과

Heracles는 공식 예제 저장소의 공개4h/long 원형을 사전 선택했다. 수익성 검증된 최고 전략이라는 뜻은 아니다. 원래 buy_params(shift15/9,ratio.16~.75),SL-25.6%,ROI표를 유지했다. 원문100일 상장기간 권고는 확인된 source-history 시작점부터100일이 지난 신호만 받는 point-in-time 제한으로 구현했다. 이는 원형 전략 코드를 수정하지 않은 별도 적용조건이며 실제 정확한 상장일을 알아냈다고 하지 않는다. 고정 market-order 실행 설정과 OHLCV 기반 SL/ROI의 순서 가정도 남긴다.

2025: 완결199건의 순손익은+331.98이지만 미완결7건의 평가가-5,183.04여서 종료손익-4,851.06이다. 비용2배-13,590.58, 같은4h평가 낙폭33,038.93 trade-bps다.2026: 완결74건+미완결5건, 종료손익+5,354.06, 비용2배+1,696.21, 같은4h평가 낙폭26,355.10이다. 해당 원형을 두 기간에서 더 나은 대체 부모로 채택할 근거는 확보하지 못했다. 이것은 모든 외부 시스템/전략이 실패한다는 결론이 아니다.

거래당 명목금액·최대 종목 슬롯은 같지만 노출은 같지 않다. Heracles 보유노출은1,774.17/718.50 symbol-days, 저장 Break는155.83/52.00이다. 이 차이를 지우고 동일위험 초과수익이나 계좌수익률로 비교하지 않는다. 표의4h평가DD는 이번에 양쪽 모두 같은 종가 grid에서 산출했으며, 과거 보고서의 일별DD와 다른 정의다.

## 3. 남는 실행 한계

이 실험은 원래 BingX futures OHLCV에 외부 엔진의 long-only SPOT matching을 적용한 가격경로 비교다. 현재 커넥터의 BingX 선물 주문 지원·청산가격·레버리지·실계좌 sizing·역사 tick/lot·체결 실패를 인증하지 않는다. analytical precision과 비구속 테스트 wallet은 비교환경 값이지 사용자 시드 가정이 아니다.

Heracles ROI/SL의 장중 정확한 체결시각은 관측하지 않았다. 원래4h봉에서 엔진이 계산한 가격을 보존하고 비용은 해당 봉 종가까지의 정산 상한으로 계산했다. 비용시각만 하한으로 바꾸면 종료손익 상한은2025 -4,730.83,2026 +5,405.72이며 이는 체결가격 불확실성의 전체 범위가 아니다. cost2는 동일 실행 경로의 비용 재평가이지 높아진 비용을 보고 ROI 의사결정을 다시 한 실험이 아니다. 현재 snapshot을 과거 실제 체결로 바꾸지 않는다.

독립 구현 확인과 독립 시장검증은 다르다. 이미 본 두 기간을 외부 엔진으로 돌렸어도 독립OOS로 바뀌지 않는다. 공식 lookahead-analysis/recursive-analysis, 실제 paper 운용, BingX 선물 연결은 이번 완료 항목이 아니다.

## 4. 재사용 판단

Freqtrade는 이 두4h 전략의 별도 개발·검산 엔진으로 실제 재사용 가능한 경로를 확보했다. 기존 엔진 전체 교체는 승인/완료하지 않는다. Break V2의 진입 구조는 양기간 외부 엔진에서도 재현됐으므로 유지할 개발 자산이다. Heracles는 부정/혼합 참조 결과로 남긴다. D/D2는 원래 비교 기준 그대로이며 이번 결과로 D3를 만들거나 새 formal 경계를 열지 않는다.

완료된 workflow에서 경제실행·다운로드·설치·git writer를 제거하고 저장결과/코드/예산 검증만 남긴다. 원래 경제 driver 자체는 동결 코드로 보존되며 이미 소진된 예산 상태에서 재실행을 거부한다. 완료를 G5 PASS 대기로 연장하지 않는다.
