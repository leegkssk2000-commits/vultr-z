# Work 실행 패키지

## 사용
새 Work에서 `leegkssk2000-commits/vultr-z`를 선택하고 이 ZIP을 첨부한다. ZIP의 `WORK_NEXT.txt` 전체를 읽고 실행하도록 지시한다. 실제 작업 시작은 Work의 시작/예약/실행 증거로 확인한다.

## 포함 파일
- `WORK_NEXT.txt`: 이번 successor의 실행 범위, Work 단일 소유권, 재발 방지 검수, 첫 배치 예산, 보고 규칙.
- `SCALP7_REBENCHMARK_AUDIT_20260916.md`: 이전 Chat 재감사 원문을 수정 없이 포함했다. 원문과 코드를 다시 대조할 출발 자료이며, 확정 SSOT·새 성과·실행 증거가 아니다.
- `MANIFEST.json`: 패키지 파일의 SHA-256. 전송 동일성 확인용이며 내용의 정확성을 보증하지 않는다.

## 이번 변경
이전 감사문서의 마지막 Chat/Work 분업과 달리, 이번 범위는 Work가 원자료 조사부터 구현·경제검증·통합까지 담당한다. Chat에서 같은 후보를 병행 실행하지 않는다.
원자료 충실도·코드 동작·경제성·fresh 승격은 서로 다른 판정이다. 기존 오류를 반복하지 않도록 첫 번째를 경제실행 전에 확인한다.
전체 현재7+재료20은 감사 대상이다. 첫 신규 경제 배치 상한은 identity6개/FULL6회이며, 새 matched control이 필요하면 그 상한에 포함한다. 이 수치는 작업 예산으로 제안·포함한 것이지 저장소의 기존 경제 승격 임계치가 아니다. 사용자가 이 지시문을 Work에 제출하는 범위에서 적용한다.
