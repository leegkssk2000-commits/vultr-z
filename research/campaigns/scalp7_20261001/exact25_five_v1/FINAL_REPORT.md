# PR #1344 동결 5개 실행·회수 결과

승인된 다섯 identity를 각각 한 번 실행했다. 누적 STARTED=5/5, COMPLETED=5, FAILED=0, 남은 FULL 예산=0이다. 기존 승인·원장·예약·잠금·프로세스·저장 결과를 먼저 확인했고, 같은 identity의 이전 실행은 발견되지 않았다. 시작·완료 이벤트와 최초 승인 기록은 수정하거나 초기화하지 않았다. 종료 후 worker/supervisor 프로세스 없음, 두 실행 잠금 해제, 잔존 partial 없음을 확인했다.

이번 완료는 동결 5개 실행·저장·검산의 완료다. 원래 25개 및 미완료 19개를 유지하며 G4 전체 완료가 아니다. 새 후보·추가 FULL·유료 지출·서비스 변경·배포·실주문·LIVE·공식 승격은 수행하지 않았다.

## 비교 해석과 한계

- ST_TRAIL은 validation 1x 손실을 23.087 USDT 줄였지만 부모 승리 21건 중 2건을 손실로 바꿨다. 부모 승리 집합의 순익 변화는 -36.014 USDT이고 양수 이익 보존율은 91.334%다. 두 ST 모델 모두 확인된 종료 거래의 비용 차감 후 합계가 음수다.
- SR_RETEST는 validation 1x 손실을 101.390 USDT 줄였으나 부모 승리 22건 중 16건을 놓치고 1건을 손실로 바꿨다. 양수 이익 보존율은 35.90%다. 첫 rolling 창의 1x 순익도 부모보다 29.663 USDT 낮았다. SR 두 모델의 부분 합계는 1x에서 소폭 양수지만 2x에서 음수다.
- SR_CONTROL은 자료 공백 이후 여섯 심볼의 포지션 소유권이 미확정으로 남아 이후 여러 창의 확인된 종료 거래가 없다. 해당 창의 확인된 거래 수 0을 전체 손익 0 또는 정상적인 무거래 성과로 읽지 않는다.
- NOISE_BASELINE은 독립 기준본이다. 이전 Rider/GMMA의 자식 개선으로 해석하지 않는다. 확인된 종료 거래 합계는 1x와 2x 모두 음수다.
- 전체 계좌 NAV는 미확정 소유권 이후 완결되지 않는다. 보고한 초반 구간 DD는 저장된 LAST 가격 표본의 DD이며, 전체 DD·봉중 손실·mark-price 청산 위험으로 대체할 수 없다.
- 과거 OHLC 체결모형과 기준 비용을 적용한 연구 결과이며 실제 계좌 실현손익이 아니다. 이미 검토한 개발용 과거자료로 fresh T=0이다. 창 경계를 넘어 나중에 확인한 rolling 거래 합산은 각 창 종료 당시의 OOS 성과가 아니다. 이 결과로 승격하지 않는다.
