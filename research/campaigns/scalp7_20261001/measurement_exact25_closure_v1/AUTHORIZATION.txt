[2. 작업 A — 공통 측정 결손을 한정해서 수선한다]
2026-02-13 자료 단절의 최초 누락 시각·심볼·원천 파일과,
그 이후 미확정 포지션·소유권·후속 주문·계좌곡선의 영향을 실제 저장 증거로 연결한다.
물리적 자료 결측, 세그먼트/시각 연결 오류, 소유권 처리, 보고 집계 문제를 구분한다.
외부 원천 확인은 해당 결손과 필요한 필드에 한정하며 기존 접근권한과 무상 범위에서만 수행한다.
동일 거래소·상품·시각의 실제 원천 회수가 가능하면 원본을 보존한 별도 데이터 버전으로 결속한다.
다른 거래소 자료·합성봉·forward-fill을 원래 체결 증거로 대체하지 않는다.
복구 불가이면 시도한 원천과 한계를 기록하고, 평가 가능한 모든 연속 구간을 손익과 무관한 동일 기준으로 정의한다.
기존 미확정 포지션을 삭제하거나 0손익으로 정리하지 않는다. 독립 구간 평가를 연속 전체 계좌 성과로 표시하지 않는다.
필요한 최소 수정과 인공 회귀시험을 실제 수행한다.
시험은 자료 단절→보유 포지션→후속 진입→계좌평가까지 연결한다.
실측 근거가 없으면 불확실성을 해소했다고 주장하지 않는다. 전략의 진입·SL·청산은 이 수선과 동시에 바꾸지 않는다.
산출물: 원인·복구 가능 여부·영향 범위, 버전별 수정 및 시험, 다음 경제비교의 공통 데이터 계약.
원천 회수를 무기한 반복하지 말고, 복구됨/복구 불가/특정 증거 대기의 결론을 남긴다.

[3. 작업 B — 미완료 구현을 실제로 진행한다]
작업 A가 막혀도 독립적인 아래 구현은 진행한다. 원래25개의 상태표를 재작성만 하고 끝내지 않는다.
우선 해결할 기존 공백은 다음과 같다.
- Keltner/HG: 확보한 원 모드 하나를 선정해 자격·첫 눌림·조건부 주문·재자격·무효화·관리를 실제 caller에 연결한다.
  경제결과를 보고 원 모드를 선택하지 않는다. 기존 양수 parent와 실패한 ADX/청산 변형은 보존한다.
- 거래량 공통 입력: AVWAP/BBIII/OBV/MFI가 공유하는 원천 필드·단위·가용시각을 검수하고,
  실제 차이가 있는 adapter와 시험만 보완한다. 자료가 없는 경우 요구 계약과 명시적 차단을 구현한다.
- Kell/Gajjala 계열: 기존 자료와 코드에서 선정·형성·진입·실패·관리 중 빠진 연결을 완성한다.
  EMA 정렬 또는 고가 돌파 하나만으로 원저자의 전체 매매법을 재현했다고 하지 않는다.
- 자료/상품 제약 항목: Anti/Soup의 역사 tick 근거, FVG의 체결 의미, Turtle의 DAILY 구조,
  Grid의 현물 재고 제약을 항목별로 보존한다. tick이 가격격자인지 체결자료인지 실제 계약의 의미부터 확인한다.
  시간봉·상품을 몰래 바꾸거나 데이터 문제를 해결했다는 명목으로 합성 증거를 만들지 않는다.
각 변경은 원문 직접 규칙/기존 동결 규칙/선언한 기계화 가설로 나누고 수치·단위·출처·버전을 연결한다.
새 모델을 연구용으로 구현할 수 있으나, 그것을 경제실행 승인이나 검증된 독립전략으로 취급하지 않는다.
기존 엔진을 재사용하고 새 프레임워크 전면 작성·공통 필터 일괄 추가·트레이더 전수조사를 반복하지 않는다.
재료의 독립매매 적자만으로 완전 폐기하거나 미검증 부품을 유효 재료로 승격하지 않는다.
정식 host 적용·B×B·등급 규칙은 현재 유효한 SSOT를 따르며 이 문서로 우회하지 않는다.
