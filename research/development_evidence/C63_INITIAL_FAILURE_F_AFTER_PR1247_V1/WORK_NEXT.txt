3. 정확한 F 규칙 — 임의 조건 추가 금지
각 포지션의 실제 native 보유시계 h를 사용한다. 신호봉이나 진입 전 봉을 보유봉으로 세지 않는다.
M[t]는 현재 계산기의 완료봉 close[t]-close[t-14] 모멘텀이다.
EMA20은 현재 native 구현·seed·시간봉·연속성 의미를 그대로 사용한다.
같은 완료봉 t에서 다음 모두를 만족할 때 추가 전량 청산 결정을 만든다.
  3 <= h <= 19
  M[t-2] > M[t-1] > M[t] > 0
  close[t] < EMA20[t]
  기존 해당 부모의 청산 사유가 없음
M의 세 관측값은 연속된 세 보유 완료봉에서 얻는다. 두 번 연속 감소를 뜻한다.
동률이면 새 F 발동 없음. M[t]<=0이면 기존 모멘텀 청산이 우선한다.
수익권 여부, B>entry, 봉 색깔, 회복 횟수, 특정 종목·연도 조건을 추가하지 않는다.
처음 두 봉에서는 F를 평가하지 않고, held20 이후에는 F가 비활성이다.
held3..19에서 매 완료봉 평가하며, 첫 실제 F 청산 결정을 native 방식으로 처리한다.
현재 종가·EMA·고정 B에 체결했다고 계산하지 않는다. 다음 실제 관측 시가를 사용한다.
현재 봉 이후 데이터로 현재 판단값·과거 판단을 바꾸지 않는다.
기존 보호청산·갭·종료경계·pending/open/censor 처리를 유지한다.
다음 체결봉이 없으면 가짜 종결 거래를 만들지 않는다. 원래 대기/미완결 의미로 남긴다.
필수 관측값이 결측/비정상/시각 불일치이면 명시적으로 실패 기록한다. 값을 만들어 넣지 않는다.

F_ONLY: 원래 C63의 진입·수량·저점/모멘텀/시간20 청산을 유지한다. R을 켜지 않는다.
B20_F: R의 held19 단회 연장 판단·기존 청산 우선·총40봉,
       생존 연장 held20의 고정 B와 held21 이후 B 이탈 청산을 그대로 유지한다.
held19에 F로 실제 청산되면 미래 연장/B 활성화를 억지로 실행하지 않는다.
'연장 판단 플래그'와 '실제로 held20 이후 보유한 것'을 구분한다.

진입 신호 생성 규칙은 고정하지만 실제 거래 목록을 고정하지 않는다.
