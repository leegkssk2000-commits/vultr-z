ZEL TOP5 — 원자료 조사 결과와 Work 인계
작성일: 2026-09-06
범위: 이번 대화에서 실제 웹 검색·문서 확인한 자료와, PR #1187 병합본의 구현 대조.
이 문서는 새 매매 실측 결과, 공식 PASS, 신규 실험 슬롯·유료 API 지출 승인이 아니다.

1. 이번에 확인한 핵심
- 인터넷에 기술적 매매의 실증과 전문 트레이더의 원자료가 존재한다.
- 현재 연구 부모의 이름과 외부 전략의 수식·거래 과정은 동일하지 않을 수 있다.
- 특정 지표의 설명을 읽은 뒤 단일 veto를 추가한 것은 원자료 전략의 재현과 다르다.
- 원자료 재현, 현재 부모와의 비교, 암호화폐 선물로의 변형은 각각 표시해야 한다.
- 원전 숫자는 원전 재현의 SOURCE_DERIVED 값이지 ZEL 운영 합격·위험 임계치가 아니다.

2. 확인한 원자료

[S1] Hudson & Urquhart — Technical trading and cryptocurrencies
출판: 온라인 2019; Annals of Operations Research 297, 191–220 (2021)
DOI: 10.1007/s10479-019-03357-1
URL: https://link.springer.com/article/10.1007/s10479-019-03357-1
읽은 범위: 출판사 공개 본문, 데이터·방법·OOS 절, Appendix의 규칙 설명.
내용: 일별 자료, 5계열 14,919규칙, 다중검정 조정. 당시 표본에 긍정적 결과가 있으나 2018년 상반기 BTC OOS는 실패하고 다른 세 암호화폐는 양수였다.
사용법: 구조적 후보군과 검증 방법 참고. 원문의 기간·시장·포지션·거래비용 정의와 ZEL의 차이를 표시. 최고 과거 파라미터를 그대로 채택하거나 14,919개를 무차별 실행하지 않는다.

[S2] Linda Bradford Raschke — AIQ Opening Bell, August 1997
공식 사이트: https://lindaraschke.net/wp-content/uploads/2026/01/august1997.pdf
확인: Holy Grail 규칙(인쇄 p.2/PDF index 1), 설명·실패 사례(p.3–4); p.2·p.4 이미지 확인.
요약: ADX14>30 상승으로 추세 확인 → EMA20 되돌림(ADX 하락 가능) → 직전 봉 고가 위 stop 진입 → swing-low 보호와 수익 관리.

이 패턴은 Keltner와 동일 전략이라고 주장하지 않는다. 눌림 family의 참고자료다.

[S3] TradingView — Supertrend / Supertrend Strategy
https://www.tradingview.com/support/solutions/43000634738-supertrend/
https://www.tradingview.com/support/solutions/43000645068-supertrend-strategy/
읽은 범위: 공식 수식·상태 갱신·전략 설명.
내용: ATR 기반 상하단 밴드가 이전 밴드와 종가에 따라 갱신되고, 상태가 전환될 때 전략 방향이 변한다.
현재 코드와의 차이: 큰 양의 1봉 수익률과 EMA20>EMA50 후 12봉 보유는 위 ATR 밴드 상태전이 전략이 아니다.
사용법: 원형 reference의 의미 확인·구현 비교. 공식 지표 문서는 수익성 증거가 아니다. 숏·반전·청산을 생략하면 해당 변형을 따로 표시한다.

[S4] Moskowitz, Ooi & Pedersen — Time Series Momentum (2012)
https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum
읽은 범위: 저자 소속 기관의 논문 소개·연구 요약.
내용: 58개 선물·선도 시장, 과거 12개월 수익률의 예측력과 시간축별 지속/반전.
사용법: 가격 추세의 연구 근거. 12개월 결과를 1h/4h 신호의 24–48시간 보유 수익성으로 바꾸어 주장하지 않는다. 세부 reference 구현 전 논문 본문의 sizing·비용·갱신 규칙을 추가 확인한다.

[S5] Shen, Urquhart & Wang — Bitcoin intraday time series momentum

사용법: 시간 정렬·session 정의의 추가 조사 후보. 초록만으로 실행 파라미터·거래비용·수익률을 만들지 않는다.

4. Work가 이어갈 방식 — 새 로드맵·새 검증기 금지

A. 조사 결과를 현재 Top5의 구체적인 명세 차이에 연결한다.
원자료의 시장·기간·신호·시간순서·주문·무효화·손절·청산·sizing·비용을 표로 정리하고, 각 항목을 원문 section/page에 연결한다. 불명확한 규칙을 그럴듯하게 채우지 않는다.

B. 원전 reference와 ZEL 변형을 분리한다.
REFERENCE_SPEC = 원전에서 확인된 완결된 거래 구조.
PARENT = 현재 동결 Top5 부모.
ADAPTATION_SPEC = ZEL에 이식하면서 변경한 정확한 부분.
여러 부분을 바꾼 reference를 단일 지표 개선으로 포장하지 않는다. 원형 전체의 비교는 개발/no-credit reference이며 운영 승격이 아니다.

C. 한 번에 하나의 코드 조건만 바꾸는 것을 절대 규칙으로 삼지 않는다.
원자료의 핵심이 순서·상태·무효화의 조합이면 그 메커니즘을 보존한 명세가 먼저다. 실제 실험은 허용 범위와 예산을 확인해 사전등록하며, 여러 부분이 달라졌으면 추가효과의 귀속을 분리한다. 기존 공용 evaluator를 재사용한다.

D. 우선 연구 대상
- 눌림 family: [S2]의 추세 확립→되돌림→진입 trigger 순서와 현재 EMA 회복의 차이.
- Supertrend family: [S3] ATR 밴드 상태전이 reference와 현재 급등 신호의 차이.
- Break/TrendRider: [S1] Appendix 및 [S4]의 신호 수명·포지션 규칙과 현재 짧은 fixed-hold의 차이.
- [S5]/[S6]는 본문 추가 확보 전 관측 가능한 조건·정확한 성과를 미확정으로 둔다.
자료가 이미 검토·실행된 정확한 계보가 있으면 그 결과를 재사용하고 중복하지 않는다.

E. 데이터·성과 제한
개발 데이터 반복 사용 이력, Break의 이미 본 validation, Top5 실패 기록 및 원본, G5B·open intent·boundary를 보존한다.
원전의 해외선물·주식·일봉·롱숏 결과를 BingX 4h 롱 성과로 직접 이식하지 않는다.
공식 G5/G6 gate와 live/order/execution 차단을 유지한다. 원전 참고자료가 있다는 이유로 권한을 열지 않는다.
이번 검색 요청으로 새로운 실험/유료 호출 슬롯이 생겼다고 가정하지 않는다. 공개 문서 조사·코드 대조는 완료하고, 실제 economic run에 추가 배정이 필요하면 후보·차이·실험 수를 한 묶음으로 제시한다.

F. 최종 산출물
또 다른 실패 요약이 아니라:
원문 근거 → 전체 규칙 → 현재 구현과 차이 → 재사용 가능한 코드 → 미확정 규칙 → 승인된 실험 범위.
실제 실행 전 수익성 PASS를 주장하지 않는다. 구현/실행/모의체결/실거래/공식 검증을 각각 구분한다.
