# STEP7 — G5A 우선 후속 작업 (공식 승인/경제 PASS 아님)

## 실제로 변경하는 것

PR1210 callable P1: 함수 이름/파일명/모듈명만 같아도 통과하던 검증을, 실제 canonical 함수 객체·globals·기본인자/closure·설치 소스에서 컴파일한 code object와 대조하도록 변경한다. source는 컴파일만 하고 실행하지 않는다. 읽기 후 전달 직전 다시 확인하며 실패하면 이미 예약한 독립 접근권을 복구하지 않는다. 외부 서명·신뢰키·비개발자 실행 신원 조건은 그대로다. Python 내부 적대적 호스트/의존성 조작을 완전히 sandbox한다는 주장이 아니다.

## G5A의 정확한 경로

현재 g5b_operational_terminal_v1.freeze_boundary는 G5A 선행 자격으로 P0–P6, 동일 후보/자료/비용에 묶인 9 complete reports, purged_oos_pass, negative_controls_superior, no_leakage, no_cherry_pick, duplicate=0, net_expectancy_bps>0, profit_factor>1, cost2x_net_bps>0를 요구한다. 기존 함수와 숫자를 변경하지 않는다.

G5B terminal의 창별 NetR/retention과 미승인 30일×3/53,813계획을 G5A의 보편적인 새 숫자 gate로 추가하지 않는다. 그렇다고 G5A의 독립 OOS/원천/대조군을 생략하지도 않는다. STEP7 자체에 적용된 미승인 G5A 전방 설계는 현재 경로에서 별도로 수정·승인이 필요하며, 이 문서는 그 권한을 대신하지 않는다.
